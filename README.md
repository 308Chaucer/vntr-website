# VNTR Advisory website

Source for the VNTR Advisory corporate website. Static HTML, CSS and JavaScript with no build step.

## Pages

- `index.html` Focus
- `approach.html` Approach
- `intelligence.html` Intelligence
- `contact.html` Contact

## Structure

- `site.css` shared styles and brand tokens
- `site.js` navigation, footer, workflow animation and scroll behavior
- `home.js`, `approach.js`, `intelligence.js` page exhibits
- `assets/` logos, isometric icons, the SLATE wordmark and the hero video

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
